# Où déposer les photos

Déposez les images dans le sous-dossier qui correspond, puis dites-le moi :
je remplace les emplacements gris du journal par les vraies photos.

| Dossier        | Contenu attendu                                                           |
|----------------|---------------------------------------------------------------------------|
| `couverture/`  | la grande photo de une, le portrait de Mamichat                           |

| `bateaux/`     | Jandira, La Souris-Blanche, Farewell, le Golden Fleece, l'Antarctique     |
| `famille/`     | Fabien « Pacha », Michaël, Karine, Marine, Elsa, Zumba, les petits-enfants |

| `temoignages/` | dessins et mots des petits-enfants (photo ou scan)                        |
| `divers/`      | tout le reste                                                             |

## Nommage

Minuscules, tirets, pas d'accents ni d'espaces. Si vous connaissez l'année,
mettez-la devant — ça m'aide à placer la photo au bon endroit dans le récit.

```
1953-lycee-carthage-classe.jpg
1979-moorea-naissance-marine.jpg
souris-blanche-pont.jpg
```

## Format

JPEG ou PNG. Inutile de recadrer ou de retoucher : le journal applique
lui-même le cadrage et la trame d'impression. Visez au moins 1200 px de large
pour les grandes photos, 600 px suffisent pour les vignettes.

## Photos et documents : deux traitements

Le journal n'a que trois encres. Une **photographie** est donc désaturée puis
ré-encrée en bleu (les ombres) et en orange ou papier (les lumières) — elle
entre dans la palette sans retouche. C'est la classe `photo__frame`.

Un **document** — un cahier, une aquarelle, une carte postale, une lettre —
garde ses couleurs : on ne le re-teinte pas, on le pose sur son papier. C'est
la classe `photo__frame--doc`. Les scans de vrais documents sont les
bienvenus : ils font merveille en pleine page.
